1. Template Overview

This developer documentation serves as the primary configuration guideline for customizing, managing, and launching the SMSPulse Portfolio & Console Template. It features zero heavy pre-processors or node build tools, allowing you to run, deploy, and style the workspace with zero technical latency.

General Core Tech-Stack

  • Markup Structure: Semantic HTML5 frameworking with WCAG 2.1 accessibility.
  • Styling Sheet: Native CSS Variables with layout modularization overrides (`style.css`, `dark-mode.css`, `rtl.css`).
  • Interactive Logic: Vanilla ES6+ modules (`main.js`, `dashboard.js`).

2. Customizing Themes & Color Palettes

Our palette is completely organized inside CSS custom properties. To swap color parameters, edit variables located under the `:root` selector inside style.css or `html[data-theme="dark"]` inside dark-mode.css.

Light Mode Code Sample (style.css):

:root {
  --bg-primary: #f5eedc;       /* Organic warm beige sand */
  --bg-secondary: #faf6ee;     /* Lighter cream background */
  --primary-color: #be5a2b;    /* Terracotta Orange primary */
  --accent-color: #4a6b53;     /* Deep forest green safe shield */
}

Dark Mode Code Sample (dark-mode.css):

html[data-theme="dark"] {
  --bg-primary: #121c15;       /* Forest green midnight block */
  --bg-card: #18261e;          /* Darker charcoal container green */
  --primary-color: #e57842;    /* Glowing copper primary */
  --accent-color: #6f9f7d;     /* Lighter sage green accent */
}

3. JS Modules & Sandbox Widgets

All interactive behaviors are powered by native Javascript elements. You can configure sliders, calculators, and simulated lists without setting up heavy external frameworks.

Configuring simulated SMS responses (main.js)

The conversation simulator dynamically appends chats to the phone screen container. To add customized triggers (e.g. coupon words, discount codes), append new keys to the match block:

if (query.includes('coupon') || query.includes('discount')) {
  appendMessage('SMSPulse: Here is your 20% code: DISCOUNT20. STOP to opt-out.', false);
}

4. TCPA & Carrier Compliance Logic

Under federal Telephone Consumer Protection Act laws, business texting is strictly audited. Our template utilizes built-in legal shield elements designed to protect your list acquisitions:

  • Explicit Checkboxes: Double opt-in checkboxes are marked as `required` on notify forms, preventing submission without explicit consent verification.
  • Quiet Hours: Abandoned checkout sequences are structured with local-hour parameters to block SMS notifications between 8:00 PM and 9:00 AM recipient local time.
  • Instant Suppression Keywords: Standard carrier unsubscribes (`STOP`, `END`, `CANCEL`) immediately trigger a localized unsubscribe suppress notice, preventing further texts in 0 seconds.

5. Developer FAQ & Help

How do I deploy this template to production?

Since this project has no build pre-processing layers, you can deploy it instantly. Upload the entire folder straight to GitHub Pages, Netlify, Vercel, or any custom Apache/Nginx static host server. Root index handles paths automatically.

How do I integrate actual text dispatching APIs?

To transition the static phone simulators or dashboard consoles to actual carrier platforms, replace simulated fetch blocks in `main.js` or `dashboard.js` with your active Twilio, Klaviyo, or Attentive API fetch sequences:

fetch('https://api.twilio.com/2010-04-01/Accounts/{SID}/Messages.json', {
  method: 'POST',
  headers: {
    'Authorization': 'Basic ' + btoa('username:password')
  },
  body: new URLSearchParams({
    'To': recipientPhone,
    'From': '+15558882000',
    'Body': messageContent
  })
});
