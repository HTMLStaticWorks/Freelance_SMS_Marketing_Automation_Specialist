# SMSPulse | Freelance SMS Marketing Automation Specialist Portfolio & Dashboard

**SMSPulse** is a state-of-the-art, premium, compliance-first portfolio and real-time dashboard template designed for **Freelance SMS Marketing Automation Specialists**. Built with robust semantic HTML5, highly responsive CSS layouts, and interactive ES6+ scripts, this template demonstrates top-tier expertise in SMS flows, TCPA compliance laws, 10DLC carrier registrations, and conversion auditing.

## 🛠️ Outstanding Built-in Interactive Tools

This template goes far beyond standard static portfolios. It contains fully functional, client-facing sandbox utilities powered by native Javascript:

1.  **Live Conversation Phone Simulator (Home Page):** Users can text active commands like `JOIN`, `YES`, or `STOP` into an interactive phone screen mock and watch real-time automated SMS reply workflows trigger automatically.
2.  **SMS Live Content Previewer (Home Page):** An interactive copywriter sandbox where clients can write SMS drafts and view instantly how character counts and carrier segments (160 chars/segment limit) format in real-time inside a cellular mock.
3.  **TCPA Compliance Risk Analyzer (Home Page):** A multi-step interactive wizard assessing campaign consent, quiet hours, and opt-out flows, producing an instantaneous compliance rating and actionable fixes.
4.  **Campaign Flow Strategy Builder (Home 2 Page):** A drag/click sandbox representing core SMS pipeline construction. Stacks trigger cards, quiet hours, and unsubscribe filters with smooth visual animations.
5.  **Interactive Carrier Fees & ROI Calculator (Services Page):** A live investment calculator. Inputs database sizes and average order sizes to dynamically compute SMS utility fees, CTR rates, conversions, and ROI ratios.
6.  **Interactive Consultation Booking Scheduler (Contact Page):** An interactive slot-reservation grid and file uploader form allowing clients to book diagnostic syncs and submit SMS draft copies for auditing.
7.  **Dynamic Campaign Console Dashboard (Dashboard Page):** A full performance suite incorporating:
    *   *Skeleton Loading Overlay:* Simulates API fetching loaders during page section swaps.
    *   *Text Approvals Console:* Interactive "Approve" and "Reject" workflows with real-time status shifts and success feedbacks.
    *   *Keyword Trigger Registry:* Real-time listing table permitting dynamic keyword registration and trash purging.
    *   *TCPA Live Audit Checklist:* A real-time auditing scoreboard where toggling compliance criteria dynamically scales rating percentages.

## 📱 Responsive Layout Breakdown

The template enforces strict visual parameters across all screen resolutions:

*   **Mobile & Tablet (360px - 768px):**
    *   *Header:* Displays exclusively the Brand Logo, Brand Name, and a responsive **Hamburger menu** on the right side.
    *   *Dashboard Header:* Features sticky non-scrolling layouts holding the RTL toggle, theme moon/sun icon, and user profile. Incorporates a sliding-sidebar **menu drawer** toggled by a left-side hamburger bars icon.
*   **Desktop (1024px - 1440px):**
    *   *Header:* Expands links across the center (`Home`, `Home 2`, `About`, `Services`, `Blog`, `Contact`, followed by a highlighted `Dashboard` shortcut). Right-side controls display the `RTL` layout toggler, `Theme` icon, and a `Login` button.
    *   *Dashboard:* Permanent sidebar fixed on the left side of the screen with a fixed non-scrolling dashboard header.

## 👨‍💻 Installation & Quick Start

1.  Open the root folder `Freelance SMS Marketing Automation Specialist/` in any IDE.
2.  Launch the project using any local web server (e.g., VS Code's **Live Server**, **NPM Lite-Server**, or **Python SimpleHTTPServer**):
    *   *Python 3:* `python -m http.server 8000`
    *   *Node:* `npx browser-sync start --server`
3.  Open `http://localhost:8000/` in your browser. The root `index.html` will instantly route you to our beautiful home page under `pages/index.html`.
